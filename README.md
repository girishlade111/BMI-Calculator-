# BMI Calculator 🏋️

A beautiful, fully client-side **Body Mass Index (BMI) calculator** in a single HTML file — no build step, no backend, no dependencies beyond CDN assets. Open it in any browser and it works.

> Built by Girish Lade — [ladestack.in](https://ladestack.in)

## Features

- **Instant BMI calculation** — enter height and weight, get your BMI with one click
- **Health category indicator** — underweight / normal / overweight / obese classification with color-coded results
- **Metric units** — height in cm, weight in kg
- **Responsive design** — works on mobile, tablet, and desktop
- **Hindi UI** — interface text in Hindi (Devanagari) with a clean, modern layout
- **Zero dependencies** — single self-contained HTML file; styling via embedded CSS, icons via Font Awesome CDN

## Tech Stack

- **HTML5** — structure
- **CSS3** — styling (embedded `<style>`)
- **Vanilla JavaScript** — BMI logic (embedded `<script>`)
- **Font Awesome 6** (CDN) — icons
- **Google Fonts** (CDN) — Noto Sans Devanagari typeface

## Quick Start

```bash
# Option 1: just open the file
open "BMI Calculator 🏋️.html"

# Option 2: serve it locally
npx serve .
# then visit http://localhost:3000/BMI%20Calculator%20%F0%9F%8F%8B%EF%B8%8F.html
```
